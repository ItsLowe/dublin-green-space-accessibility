# Data sources, source filenames and attribution

The source description below cross-references (1) the submitted coursework’s source table and (2) a static XML/filename review of the private ProjectFiles archive and `ProjectDublin.qgz`. The project was not opened in QGIS, the GIS analysis was not run, and no GIS features/rows were inspected or recalculated. The original ProjectFiles archive, QGIS project and GIS data are excluded from this candidate. Local machine paths are intentionally omitted.
